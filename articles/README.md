# Articles Folder Layout

## drafts/

Working copies of posts that are still being edited.

## published/

Final or near-final posts that are ready to publish or have already been
published.

## Naming

Use date-prefixed slugs for posts when practical, for example:

- 2026-7-25-institutional-scramble.md
- 2026-7-20-social-media-swamp-monsters.md

If you need a working filename for an in-progress draft, a short descriptive
name is fine.
