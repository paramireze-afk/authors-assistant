# 003 — Documentation Refresh

## Why this update exists

Authors Assistant started as a focused Markdown revision CLI. The project has since evolved into a local-first Markdown authoring and knowledge management system with reusable prompts, organized research, and author-centered workflows.

This refresh aligns core documentation with current reality while preserving the project’s original spirit: practical writing support, clear boundaries, and simple maintainable design.

## Refresh goals

- Reflect the local-first philosophy across project docs
- Reinforce Markdown as the source of truth
- Clarify that AI assists the author and does not replace authorship
- Prefer maintainability over cleverness
- Keep architecture simple and incremental
- Document reusable prompts and workflow-oriented design
- Emphasize knowledge management and research organization
- Remove outdated framing tied to a narrow “Version 1 only” tool description
