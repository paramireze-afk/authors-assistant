# Knowledge Base

## Purpose

This directory contains reusable context documents intended to support AI-assisted writing.

These files are **not articles**.

Each file should be self-contained and provide reusable context for future prompts.

## Principles

- Prefer facts over conclusions.
- Keep reference material separate from analysis.
- Link related documents instead of duplicating content.
- If information is uncertain, indicate that.
- Optimize for AI retrieval and reuse rather than readability.

## Directory Structure

people/
organizations/
events/
concepts/
topics/
evidence/
sources/
characters/

**Tier descriptions:**
- `people/` — individual profiles
- `organizations/` — institutional and group profiles
- `events/` — specific historical events
- `concepts/` — recurring ideas, frameworks, and doctrines
- `topics/` — deep-dive research notes spanning multiple sources on a focused subject
- `evidence/` — specific evidence items and forensic records
- `sources/` — source and reference metadata
- `characters/` — fictional or composite character studies

## Relationship Between Files

People reference events.

Events reference evidence.

Concepts explain recurring ideas.

Sources describe where information originated.

Evidence documents specific pieces of evidence.
