# Goal

Create a personal encyclopedia that represents my current understanding of important topics.

The knowledge base should become the primary context used by AI when helping me write.

---

# Why

- Capture my own understanding.
- Reduce repeating myself.
- Give AI consistent context.
- Separate my knowledge from individual articles.

---

# Requirements

- Markdown only.
- One topic per file.
- Human readable.
- Git friendly.
- Easy to link together.
