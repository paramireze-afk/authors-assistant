# Copilot Context

## Project

Author's Assistant is a small TypeScript command-line application that uses the
OpenAI API to revise Markdown writing.

## Development Principles

- Keep the implementation small and understandable.
- Favor readability over cleverness.
- Build one feature at a time.
- Avoid unnecessary abstractions.
- Do not introduce a framework unless the project clearly requires one.
- Do not add a database.
- Do not overwrite source documents.
- Handle errors clearly.
- Keep prompts separate from application code.
- Explain meaningful implementation decisions.

## Current Milestone

The current milestone is to revise Markdown files locally using the OpenAI API
and save the result as a separate file.

Do not overwrite the original draft.
